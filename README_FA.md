رخش یک ربات تلگرام است که فایل‌ها را از تلگرام یا URLهای خارجی دریافت می‌کند، آن‌ها را به‌صورت محلی ذخیره می‌کند و لینک‌های دانلود مستقیم و مخفی از طریق HTTP ارائه می‌دهد.

---

## حالت‌های اجرا

### bot_api (پیش‌فرض)

* استفاده از Telegram Bot API با polling (`getUpdates`)
* پشتیبانی از:

  * URLها
  * اسناد، تصاویر، ویدیوها، صدا، ویس، ویدیو نوت
* امکان استفاده از MTProto به‌عنوان fallback برای فایل‌های بزرگ تلگرام

### mtproto_user

* استفاده از یک اکانت کاربری تلگرام از طریق MTProto (برای مقداردهی اولیه از زیر‌دستور `mtproto-session` استفاده کنید)
* نیازمند:

  * `api_id`
  * `api_hash`
  * فایل session (این فایل را در محل امن نگه دارید - مسیر پیش‌فرض صرفاً برای سادگی است)

---

## fallback برای فایل‌های بزرگ (Bot API + MTProto)

زمانی که `telegram.mtproto.fallback_enabled: true` باشد:

1. ابتدا تلاش برای دانلود از طریق Bot API
2. در صورت خطا، تلاش مجدد با MTProto
3. اگر `fallback_forward_chat_id` تنظیم شده باشد:

   * ربات پیام را به یک کانال فوروارد می‌کند
   * MTProto از پیام فوروارد شده دانلود می‌کند
4. اگر پیام از سمت کاربر MTProto باشد:

   * دریافت مستقیم انجام می‌شود

نیازمندی‌ها:

* session مربوط به MTProto باید احراز هویت شده باشد
* اکانت MTProto باید به چت مبدأ دسترسی داشته باشد
* یا از `fallback_forward_chat_id` به‌عنوان واسط استفاده شود

پیکربندی پیشنهادی:

* استفاده از یک کانال خصوصی به‌عنوان مقصد relay
* اطمینان از دسترسی اکانت MTProto به آن کانال
* دریافت `chat_id` با دستور `/ids`
* استفاده از مقدار به‌دست‌آمده در `fallback_forward_chat_id`
* هم کاربر و هم ربات باید در کانال عضو باشند و توانایی ارسال پیام داشته باشند

---

## قابلیت‌ها

* پشتیبانی از پراکسی SOCKS5 برای تمام ترافیک خروجی
* دانلود قابل ازسرگیری با استفاده از HTTP Range (فایل‌های `.part`)
* پشتیبانی از فایل‌های کوچک (>20Mb) و بزرگ (<20Mb) تلگرام
* سرور HTTP داخلی برای ارائه فایل
* ایمن‌سازی لینک با هش MD5 در نام فایل و query
* نمایش پیشرفت دانلود به‌صورت زنده با ویرایش پیام
* خاموش شدن آگاه از context
* لاگ‌گیری ساخت‌یافته

## راه‌اندازی MTProto

با استفاده از `mtproto-session` این تنظیمات به‌صورت خودکار انجام می‌شود. اطلاعات بیشتر در بخش اجرا آمده است.

روش دستی:

> فیلدهای موردنیاز:
>
> * `telegram.mtproto.api_id`
> * `telegram.mtproto.api_hash`
> * `telegram.mtproto.session_file`

### دریافت API Credentials

1. مراجعه به: https://my.telegram.org/apps
2. ایجاد یک application
3. کپی `api_id` و `api_hash`

---

### تنظیم Relay Chat ID

1. ایجاد یک کانال یا چت خصوصی
2. ارسال `/ids` به ربات
3. استخراج `chat_id` از پاسخ
4. تنظیم آن در `fallback_forward_chat_id`

---

## اجرا

اجرای برنامه:

```bash
go run . -c config.yaml
```

ایجاد session برای MTProto:

```bash
go run . mtproto-session
```

یا با پارامترهای مشخص:

```bash
go run . mtproto-session \
  --session ./secrets/mtproto.session \
  --api-id 12345 \
  --api-hash "0123456789abcdef0123456789abcdef"
```

این فرایند:

* دریافت مقادیر ناقص از کاربر
* انجام لاگین
* ذخیره session
* نمایش وضعیت احراز هویت
